Steam client (Linux, arm64) - packages for DroidDeck's local install
====================================================================

DroidDeck cannot ship Valve's Steam client - it is not redistributable - so a Steam session
downloads it from Valve's CDN the first time it runs. On a network where that CDN is slow or
unreachable, fetch the packages here and install them from DroidDeck's Steam settings
("Steam client" row -> "From folder").

Branch    : steamdeck_publicbeta   (what Deck mode uses; the same client as publicbeta's arm64)
Version   : 1791249696
Components: 17 files, 360,276,198 bytes (343.6 MiB) compressed, ~932 MB unpacked
Taken from: Valve's manifest on 2026-10-07. Valve replaces these files whenever it updates the
            client, so this list goes stale - `download-steam-client.bat --list` prints the
            current one, and the tool itself always follows the manifest rather than this list.

Downloading: run `download-steam-client.bat` at the project root. It fills
FirstLocalInstall\steam-client - alongside the runtime and Proton archives this checkout keeps for
local installs - with the 17 packages plus the manifest, verifying each one against the manifest's
sha256, and resumes wherever it left off if it is run again. `--out DIR` puts them elsewhere.

The rest of that folder, which the play page's "First-time local install" button installs in this
order: linuxfs.tar.zst (the runtime), the Proton <build>.tar.zst, steam-client\, desktop.tar.zst
(the LXQt desktop) and fonts\ (CJK fonts, copied into the rootfs's /usr/share/fonts/TTF and picked
up by fontconfig). The desktop's own entry - its download, its size and its sha256 - is in the
hosted catalog, so what is below is a snapshot of it, not the source:

    https://raw.githubusercontent.com/The412Banner/winlator-contents/main/desktop.json

    id `desktop`, "Desktop (LXQt on labwc)", kind tar, version r1, 426,049,032 bytes
    https://github.com/The412Banner/winlator-contents/releases/download/steamdeck-desktop-r1/desktop.tar.zst
    sha256 c2bb860b3b1688287451e2495be5db313ec07f8c8af501dfac2768a9f417bc86

From a network that cannot reach github.com, the same file comes through one of the app's
accelerators - `https://gh-proxy.com/<url above>` was the fastest of them on 2026-10-07.

The button that offers all of this belongs while the device is short of any of it. The runtime,
Valve's Proton and the client always count; the rest is read off the folder the last run came
from, which the app remembers - while that folder still holds something the device has not got
(the desktop, fonts, a third-party Proton) the button stays, and it goes once everything in it is
in. With no folder remembered - none picked yet, or the one picked taken off the device - the
desktop's own check stands in.

The folder is handed to the runtime's droiddeck-steam-install, which reads the manifest, uses
every component it finds in the folder and downloads only the rest. Each file - local copy or
download - is checked against the sha256 in the manifest, so a truncated or renamed file is
rejected rather than installed. Nothing needs to be renamed by hand: the file names below are
the names the manifest itself uses.

Using it
--------

1. Put all 17 files (and the manifest, if the device has no network at all) in one folder - any
   name, any location, but flat: the install reads that folder's own entries, not subfolders.
2. Copy the folder to the device, e.g. /storage/emulated/0/Download/steam-client.
3. DroidDeck -> Steam settings -> Steam client -> "From folder", and pick it.
4. The install needs about 2 GB free: the client unpacks to a little under 1 GB, and one
   component's zip sits beside it while it is being unpacked.

The row only appears while the client is missing. Repairing a client that is already installed
is the "Repair Steam client" button above it - but note that a repair re-downloads from Valve
rather than from the folder.
